# Screens — F001_PublicLanding

## Screen List

| Screen Name | What User Sees | What User Can Do |
|------------|----------------|-----------------|
| HomePage | Hero section with platform tagline, content grid of featured quiz sets, flashcard sets, and exam rooms | Browse content, click Login or Register CTA |
| AboutPage | Static page describing the platform's mission, team, and features | Read content |
| ContactPage | Contact form with name, email, and message fields | Fill and submit the contact form |
| TermsPage | Platform terms of service | Read content |
| PrivacyPage | Platform privacy policy | Read content |
| CookiesPage | Cookie usage policy | Read content |
| SecurityPage | Security practices and data protection information | Read content |

## User Journey

1. User arrives at HomePage and sees featured quiz sets, flashcard sets, and exam rooms in the content grid.
2. User clicks the Login button in the navigation → navigated to LoginPage.
3. User clicks the Register button in the navigation → navigated to RegisterPage.
4. Alternatively, user clicks Contact in the footer → navigated to ContactPage.
5. User fills the contact form (name, email, message) and clicks Submit → sees success confirmation.
6. User clicks About, Terms, Privacy, Cookies, or Security in the footer → navigated to the respective informational page.
